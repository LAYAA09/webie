# CityRun Marathon 2026

**Hackathon Project | Responsive Marathon Registration Interface**

## Overview
CityRun Marathon 2026 is a front-end web development project designed to provide a modern and interactive marathon registration experience. It showcases marathon route visualization, checkpoint distances, participant registration forms, and responsive UI design.

## Key Features
- Responsive layout for desktop and mobile devices
- Animated marathon route with runner and checkpoints
- 5 KM, 10 KM, and 21 KM marathon categories
- Registration form with HTML input validation
- Medical information and safety guidelines
- Modern styling with CSS animations and hover effects

## Technologies Used
- HTML5
- CSS3
- CSS Grid and Flexbox
- CSS Animations and Transitions

## Project Objective
To demonstrate front-end web development skills through an interactive and responsive event registration interface.

## Project Status
Front-end prototype. Backend integration and database storage are not implemented.

## Future Enhancements
- Backend integration
- Database connectivity
- Participant registration management
- Registration confirmation system

## Disclaimer
This is a demonstration project. Event details and registration capacity are illustrative.
